Connect Gmail

Job-Agent uses Google's Gmail API with read-only access. OAuth credentials and a token are stored on this computer. The app does not send, delete, archive, or label email.

1. Install the Gmail dependencies

From the repository root, activate your virtual environment and run:

python -m pip install -e ".[gmail]"

2. Enable the Gmail API

  1. Open the Google Cloud Console and create or select a project.
  2. Enable the Gmail API for that project.

3. Create an OAuth Desktop client

  1. Configure Google Auth Platform's branding and audience. For a personal Gmail account, choose External and add your Google account as a test user while the app is in Testing.
  2. Under Clients, create an OAuth client ID with application type Desktop app.
  3. Download the JSON file. Save it in your repository as config/gmail-credentials.json. Keep this file private; Git ignores it.

4. Connect and sync

Restart the dashboard with job-agent start, click Connect Gmail, then follow Google's consent flow in your browser. The requested permission is Gmail read-only. Once connected, use Sync now or turn on automatic syncing to check every 15 minutes while the dashboard is running.

How updates work

  • Job-Agent checks recent emails that mention application, interview, offer, or recruiter activity.
  • Only explicit application-status wording is considered for updates.
  • High-confidence company-and-role matches can update the tracker automatically.
  • Ambiguous or unmatched emails appear in Email review queue, where you choose the tracked job before approving the update.
  • Only message metadata and a short preview are stored; full message bodies are processed in memory and not saved.
Google OAuth testing note: external apps left in Testing can have refresh tokens expire after seven days when using Gmail scopes. If Gmail stops syncing, reconnect in the dashboard. Do not publish this personal OAuth client as a public application without reviewing Google's verification and data-use requirements.

Disconnect

Use Disconnect in the dashboard to remove the saved local token and disable automatic sync. To revoke the Google grant as well, remove Job-Agent from your Google Account connections.
